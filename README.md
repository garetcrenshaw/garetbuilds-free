## How to use a Claude skill (03 and 04)

A skill is a folder with a `SKILL.md` file that teaches Claude a repeatable job.

- **Claude Code:** copy the folder into `~/.claude/skills/`. Then just ask, for example "kiddo, what does this error mean?"
- **Claude.ai:** go to Settings → Capabilities → Skills, and upload the folder as a zip.
