# Hook filter

Most short videos lose people in the first few seconds, usually because the opening is vague, the best line is buried at the end, or it's full of words a stranger doesn't get.

Paste your script or transcript and the hook filter runs six checks, then hands back one tightened, ready-to-record script:

1. Is it specific and clear on the first listen?
2. Could a third-grader follow it?
3. Is there a real detail or stake the viewer cares about?
4. Is the strongest line in the first ten seconds?
5. Does every sentence serve the promise?
6. Does the ending pay off what the opening promised?

It never invents numbers or results to make a hook punchier.

## Install
- **Claude Code:** copy this folder to `~/.claude/skills/hook-filter/`
- **Claude.ai:** Settings → Capabilities → Skills → upload this folder as a zip

## Use
> hook filter this script: [paste]
