# Kiddo

AI loves to answer in jargon, run IDs and walls of text. Kiddo makes it explain things the way a good friend would: what's wrong, what it's doing about it, and the one thing you need to do. Plain words, about third-grade reading level, with none of the facts dumbed down.

It's the skill I use most.

## Install
- **Claude Code:** copy this folder to `~/.claude/skills/kiddo/`
- **Claude.ai:** Settings → Capabilities → Skills → upload this folder as a zip

## Use
Add "kiddo" to any question:

> kiddo, why won't my website load?

Before: *"The DNS A record propagation is incomplete and the TLS handshake fails at the edge…"*
After: *"Your new web address isn't pointing at your site yet. That usually fixes itself within an hour. You don't need to do anything right now."*
